# AdminAllSpec (SwiftlyS2)
Allows admins to spec both teams with `mp_forcecamera 1`.

> [!IMPORTANT]  
> [qstage](https://github.com/qstage) is the creator of this plugin.<br>
> Original: https://forums.alliedmods.net/showthread.php?t=182412

## ConVars
**`css_adminallspec_flag`** - Default admin flag: *admin.generic*)

## Requirments
- [SwiftlyS2](https://github.com/swiftly-solution/swiftlys2)
